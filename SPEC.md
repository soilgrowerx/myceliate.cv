# Myceliate.cv - Conversational Resume/Profile

## Project Overview
- **Name:** myceliate.cv
- **Purpose:** Conversational CV/resume that answers questions about George Steward
- **URL:** https://myceliate.cv (purchased)
- **Brain Backend:** https://mycelial-brain-mcp-1084814124987.us-central1.run.app

## What It Is
A web page where visitors type questions about George and get intelligent answers drawn from his brain (knowledge base).

## Core Features
1. Simple input box on webpage
2. User types question (e.g., "What's George's background?")
3. Backend queries Mycelial Brain
4. Returns relevant information
